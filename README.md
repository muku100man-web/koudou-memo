# 行動メモ

どこへ行って、何をしたかを一言で残す、自分用の記録帳（iPhone向けWebアプリ）。

- ログイン不要。記録はすべて端末内（IndexedDB）に保存する
- 記録する内容：日時（自動、あとから直せる）、場所の名前、住所（「現在地」ボタンで自動入力）、メモ、写真
- 報告に使う場所（初期値：リサイクルセンター／北西粗大／大安粗大／藤原粗大）はボタンで選べる
- ワンタップボタン（初期値：約束／覚え／いただきもの）を押すとメモに入る
- 「月のまとめ」：その月に報告対象の場所へ行った日を一覧表示し、Excelに貼りつけられる形でコピーできる
- ホーム画面に追加してアプリとして使える（オフライン対応）
- バックアップの書き出し・読み込み（JSONファイル、写真込み）

## 外部との通信

「現在地」ボタンを押したときだけ、緯度・経度を住所検索サービスに送る。

1. 国土地理院 逆ジオコーダー（mreversegeocoder.gsi.go.jp）と市区町村コード表（maps.gsi.go.jp/js/muni.js）
2. 1 が使えないときは OpenStreetMap Nominatim

通信できないときは位置（緯度・経度）だけを保存し、住所は空欄になる。

## ファイル構成

| ファイル | 役割 |
|---|---|
| index.html / style.css / app.js | アプリ本体 |
| sw.js | オフライン用のキャッシュ |
| manifest.webmanifest / icons/ | ホーム画面用の名前とアイコン |

## 公開（GitHub Pages）

1. リポジトリの Settings → Pages → Branch を `main` / `/ (root)` にして保存
2. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される
3. iPhone の Safari で開き、共有ボタン →「ホーム画面に追加」

※ GitHub Pages は無料プランだと公開リポジトリでしか使えない。

## 更新するとき

`sw.js` の `CACHE` と `app.js` の `APP_VERSION` の番号を上げてから公開すると、端末にも新しい版が届く。
